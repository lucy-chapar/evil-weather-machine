# Digital Sand Toy

Carrier PCB and weather/shot-day firmware for the PrintKits Digital Sand kit. See `README.md`.
Only `pcb/`, `firmware/weather/` and the top-level docs are in git; other folders here (the finder puck)
are local and ignored.

## PCB

The KiCad 7 carrier PCB is in `pcb/`; see `pcb/README.md`.

- Everything in `pcb/` except `README.md` is generated by `pcb/tools/generate_kicad.py`.
  Placement, tracks and silkscreen text are constants in that script.
- Regenerate with KiCad 7's bundled Python, which provides `pcbnew`:
  `/Applications/KiCad/KiCad.app/Contents/Frameworks/Python.framework/Versions/Current/bin/python3 pcb/tools/generate_kicad.py`
- The script exits if the schematic netlist stops matching `EXPECTED_NETS` (the kit wiring).
  It also prints a DRC summary; the expected result is no violations and 0 unconnected pads.
  The `lib_footprint_issues` it reports only appear because standalone scripts don't load KiCad's global footprint table.
- KiCad 7 has no command-line ERC; run ERC in Eeschema after schematic changes.
- If the board has been edited by hand in KiCad, don't rerun the script, because it overwrites the files.

## Weather firmware

`firmware/weather/` is a PlatformIO project (ESP32, Arduino) that shows today's Open-Meteo forecast on the 8x8 panel.

- Build: `cd firmware/weather && pio run` (add `-t upload` to flash). Platform is pinned to `espressif32@6.4.0`.
  `pio run -e demo -t upload` flashes a demo (`DEMO_MODE`) that loops every screen without WiFi.
  `pio run -e ota -t upload` updates over WiFi (ArduinoOTA, `digitalsand.local`, password in uncommitted
  `firmware/weather/ota_password.ini`, see the `.example.ini`);
  only works once a non-demo build is on the toy. From a Claude session it needs the sandbox off (LAN UDP is
  blocked inside it: "No route to host"). An upload can fail if the toy is mid forecast fetch; just retry.
- This kit's panel needs `MATRIX_ROTATION 3` and `MATRIX_FLIP_X true` (checked on hardware).
- Icons and font are text art in `src/art.h`; after editing them run `python3 tools/preview_art.py`.
  It mirrors the particle effects in `main.cpp`, so keep the two in step.
